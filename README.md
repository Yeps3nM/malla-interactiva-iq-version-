### Malla Interactiva Ingeniería Química UCH

#### El presente repositorio tiene el desarrollo del front end para la malla curricular actualizada de IQ. 

`IMPORTANTE: El código original base, el cual fue "forkeado" manualmente es de propiedad del github de dcc uch, que es desarrollado para su programa de ingeniería en computación.`

Este código cambia esencialmente:
1. Existencia de versiones de la malla
2. Archivo con los datos de los cursos
3. Colores
4. Versiones de los paquetes
5. Cambio en la validación de los cursos activos, por caso de ramos sin código (uso de identificadores únicos de componentes de vue)

#### Visita el sitio web : https://malla-iq.pages.dev/
